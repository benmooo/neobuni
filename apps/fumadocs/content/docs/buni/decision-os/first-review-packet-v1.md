# Jev 首批人工评审包 V1

> DRI：用户（Buni 产品负责人）
> 目的：将工程提供的草案样本变成你已审核的标准答案。
> 状态：DRI 于 2026-10-22 审核通过全部五项建议答案；此文件本身不改变 release gate。

## 如何评审

每一题只需判断工程给出的「建议标准答案」是否正确。你可以回复：

- `1 对，2 对，3 改为……`；或
- `全部通过`；或
- 对任一题写「不确定」，该题会继续保留为 draft，绝不会进入 release gate。

这不是在判断 Jev 的答案，而是在先定义 **Buni 应该怎样做才算对**。

## 评审后的动作

在你确认后，工程会：

1. 只把你明确通过的样本标记为 `reviewed`；
2. 在记录中写明 DRI、日期、理由与问题版本；
3. 运行 Jev replay；
4. 把结果与 release gate 一起交给你决定是否开启极小范围的路由。

即使五题全部通过，它们也只是首批基准，**不自动开启** Jev 路由。

这三题不决定“做什么”，只判断“现在是否值得用一条建议打断用户”。当前实现只记录分数；它不会发送通知、改变建议、创建动作或授权执行。
